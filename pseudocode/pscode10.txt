ALGORITHM: AppCleaner-MRU-List  (move-to-front linked list)
 
DATA STRUCTURE
	app_t : struct of {appName, freq}
	appList : LINKED LIST OF app_t		// HEAD = least-frequently-used,
                                        // TAIL = most-frequently-used
--------------------------------------------------------------
STEP 0: INITIALISATION
--------------------------------------------------------------
 1. CREATE empty list appList
--------------------------------------------------------------
STEP 1: MENU-DRIVEN MAIN
--------------------------------------------------------------
 2. LOOP
 3.      DISPLAY MENU: 1) Open app   2) Clean   3) Exit
 4.      READ choice
 5.      CASE choice OF
 6.      -- Option 1: the user opens an app ------------------------------
 7.      1: READ appName
 8.         found <- FALSE
 9.         i <- 0
			delete_index <- NULL
			insert_index <- NULL
10.         FOR EACH node IN appList DO
11.               IF NOT found AND node.name = appName THEN
						app_to_update <- node
						INC app_to_update->freq
						delete_index <- i
14.                     found <- TRUE
15.                     CONTINUE
				  ELSE IF found AND app_to_update->freq < node->freq THEN
						insert_index <- i
						BREAK
16.               END IF
17.               i <- i + 1
18.         END FOR
			IF insert_index IS NOT NULL THEN
				INSERT app_to_update at insert_index of appList
			ELSE IF found THEN
				INSERT app_to_update at TAIL of appList
			ENDIF
			IF delete_index is NOT NULL THEN
				DELETE node at delete_index of appList// old copy of app with outdated freq
			ENDIF
19.         IF NOT found THEN
20.               INSERT {appName, 1} AT HEAD OF appList //opened for first time
21.         END IF
22.      -- Option 2: uninstall the least-recently-used app -------------
23.      2: IF DELETE TAIL OF appList SUCCEEDS (an app was removed) THEN
24.               OUTPUT "Deleted app:", app.name
25.         ELSE
26.               OUTPUT "Empty"
27.         END IF
28.      -- Option 3: quit -------------------------------------------------
29.      3: EXIT LOOP
30.      END CASE
31. END LOOP
32. DESTROY appList
 
--------------------------------------------------------------
COMPLEXITY: Open costs O(n) in the worst case (linear search,
then an O(1) move-to-front); Clean (evict the least-used app)
needs the tail of a singly linked list, which also costs O(n).
Here n = number of apps currently tracked.
